# UI audit — 2026-10-05 (after M22, before M17)

ตรวจหน้า NOC และ `/admin` ด้วย Playwright (`tests/e2e`, 1920 มืด / 1366 สว่าง / มือถือ 390) บน stack ในเครื่อง โหมดสาธิต
เทียบกับเกณฑ์ WCAG 2.2 AA และกฎ ui-ux-pro-max (accessibility, touch, typography)

## ผ่านอยู่แล้ว

- ปุ่มไอคอนมี `aria-label` (วิธีใช้, ธีม, ปิด, ย่อแผง), แถวแจ้งเตือน/ประวัติ/ไม่มีตำแหน่งกดด้วยคีย์บอร์ดได้ (`tabIndex` + Enter)
- focus ring `:focus-visible` ทุก control, `prefers-reduced-motion` ปิดแอนิเมชัน, ไม่ปิด zoom, ไม่มี emoji เป็นไอคอน
- สถานะไม่ได้ใช้สีอย่างเดียว (มีสัญลักษณ์ ● ▲ ✕ ○ ◆ + ข้อความ), ไม่มีข้อความเลยขอบใน 3 ขนาด
