# M01 — monorepo + CI พื้นฐาน

## หน้าที่

วางโครง monorepo ชั้นบนตาม ADR-0009, เครื่องมือคุณภาพโค้ด และ CI พื้นฐานบน Gitea Actions — ยังไม่มีฟีเจอร์

## สิ่งที่สร้าง

- pnpm workspaces + Turborepo (`lint`, `typecheck`, `test`, `build`)
- `tsconfig.base.json` (strict), ESLint flat config + Prettier, Vitest
- `apps/web` หน้าเดียวแสดงชื่อระบบ, `apps/api` `GET /health` → `{"status":"ok","version":"0.1.0"}`, `apps/worker` log ตอนเริ่ม
- `packages/shared` (`BUILDING_CODES`, zod schema ตัวอย่าง), `packages/db`, `packages/ui` ว่าง
- dependency-cruiser บังคับทิศทาง import
- `.gitea/workflows/ci.yml` (job `quality`, `secrets`, `audit`) และ `build.yml` (job `build`)
- `docs/architecture.md`, ADR 0001–0017, PR template, `renovate.json`, `CONTRIBUTING.md`

## วิธีรันในเครื่อง

```bash
nvm use                # Node 24 LTS
corepack enable        # pnpm 10.28.0
pnpm install
pnpm --filter @sbc-noc/api dev      # http://localhost:3001/health
pnpm --filter @sbc-noc/web dev      # http://localhost:5173
pnpm --filter @sbc-noc/worker dev
```

## วิธีทดสอบ

```bash
pnpm format:check
pnpm lint
pnpm depcruise         # ทิศทาง import
pnpm typecheck
pnpm test
pnpm build
pnpm audit --audit-level=high
```

ทดสอบเงื่อนไขเสร็จ (ขั้น 7):

- **gitleaks:** อย่าใช้ `AKIAIOSFODNN7EXAMPLE` — ค่านี้อยู่ใน allowlist ของ gitleaks (key ที่ลงท้าย `EXAMPLE` ถูกข้าม) CI จะ**ไม่**ล้ม ให้สร้าง key ปลอมรูปแบบ AWS ที่ไม่ลงท้าย EXAMPLE แทน:
  `echo "aws_access_key_id = \"AKIA$(tr -dc 'A-Z2-7' </dev/urandom | head -c 16)\"" > leak.txt`
- **ทิศทาง import:** เพิ่ม `import '@sbc-noc/db';` ใน `apps/web/src/main.tsx` → `pnpm depcruise` รายงาน `web-no-db`

## ข้อจำกัด

- `runs-on: ubuntu-latest` ต้องตรงกับ label ของ act_runner ที่ใช้ร่วมกับ Portal — แก้ตาม label จริง
- job ใช้ container `node:24-bookworm` + `--cpus/--memory` — ถ้า runner ไม่อนุญาต container options จะไม่มีผล
- runner ต้องดึง `actions/checkout@v4`, `actions/cache@v4` และ release ของ gitleaks จาก GitHub ได้ ถ้าไม่ได้ให้ mirror ไว้ใน Gitea
- `actions/cache` ต้องเปิด cache server ของ act_runner
- ยังไม่ build/push image ไม่ deploy (M17)
