# ADR-0001: เลข LOC

- **สถานะ:** Accepted
- **วันที่:** 2026-10-02

## บริบท

ทุกพื้นที่ (ห้อง/ตู้) ต้องมีเลข LOC เดียวกันทั้งใน sbc-noc และ SBC ASSET เพื่อไม่ให้เลขชนกัน

## การตัดสินใจ

- LOC-187 คือห้อง server
- ห้องใหม่ออกเลขจากฐาน `sbc_noc` เริ่มที่ LOC-188 เรียงต่อไป
- SBC ASSET ไม่ออกเลขเอง แต่ขอเลขจาก sbc-noc

## ผลที่ตามมา

- sbc-noc เป็นเจ้าของลำดับเลข LOC ต้องมี API/ขั้นตอนออกเลขให้ SBC ASSET
- เลขที่ออกแล้วห้ามนำกลับมาใช้ซ้ำ
