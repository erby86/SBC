# ADR-0011: ล็อกอินเมื่ออินเทอร์เน็ตล่ม

- **สถานะ:** Superseded บางส่วนโดย ADR-0023 (บัญชีฉุกเฉินและ token จอทีวีเลิกใช้; session 12 ชั่วโมงคงเดิม)
- **วันที่:** 2026-10-02

## บริบท

ล็อกอินหลักผ่าน OIDC ซึ่งอาจใช้ไม่ได้เมื่ออินเทอร์เน็ตล่ม แต่เป็นช่วงที่ NOC จำเป็นที่สุด

## การตัดสินใจ

- มีบัญชีฉุกเฉิน 2 บัญชีในเครื่อง พร้อม TOTP
- จอทีวีแสดงผลใช้ token เฉพาะแบบอ่านอย่างเดียว
- session อายุ 12 ชั่วโมง

## ผลที่ตามมา

- ต้องเก็บรหัสและ TOTP seed บัญชีฉุกเฉินนอกระบบอย่างปลอดภัย
- ทุกการใช้บัญชีฉุกเฉินต้องลง audit log
