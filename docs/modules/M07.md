# M07 — รายงานตรวจความครบ

ตาม modules-by-gate-v2: query/หน้าเรียบง่าย — ไม่มีชั้น/ห้อง, IP ซ้ำ, uplink ชี้อุปกรณ์ที่ไม่มี, วงวน uplink, อุปกรณ์ไม่มีใน Zabbix

**เสร็จเมื่อ:** รายงานเป็นศูนย์รายการผิดพลาด (เงื่อนไขปิด G1)

## สิ่งที่สร้าง

| ส่วน                                  | ที่อยู่                                                        |
| ------------------------------------- | -------------------------------------------------------------- |
| ชุดตรวจ (SQL) + `runRegistryChecks()` | `packages/db/src/checks.ts`                                    |
| รูปแบบรายงาน (zod) ใช้ร่วม api/web    | `packages/shared/src/registry-checks.ts`                       |
| CLI (exit 1 ถ้ามี error)              | `packages/db/src/check-cli.ts`                                 |
| API อ่านอย่างเดียว                    | `GET /registry/checks` ใน `apps/api`                           |
| หน้าเรียบง่าย                         | ส่วน "รายงานตรวจความครบของทะเบียน" ใน `http://noc-dev.sbc.lan` |

| ตรวจ             | ระดับ   | ความหมาย                                                                  |
| ---------------- | ------- | ------------------------------------------------------------------------- |
| `no_position`    | error   | ไม่มีทั้งชั้นและห้อง (นอกจาก wan/controller) — schema CHECK กันไว้อีกชั้น |
| `duplicate_ip`   | error   | IP จัดการซ้ำ                                                              |
| `uplink_missing` | error   | uplink ชี้ไปอุปกรณ์ที่ถูกลบ                                               |
| `uplink_cycle`   | error   | uplink วนเป็นวง (recursive CTE)                                           |
| `not_in_zabbix`  | error   | อุปกรณ์ active ในบทบาทที่ `monitored` แต่ไม่มี `external_refs` ของ zabbix |
| `sample_data`    | error   | แถว `data_status = 'sample'` (ADR-0014)                                   |
| `no_room`        | warning | มีแค่ชั้น ยังไม่มี LOC                                                    |
| `no_uplink`      | warning | ไม่มี uplink (ยกเว้น role core)                                           |
| `no_mgmt_ip`     | warning | บทบาทที่เฝ้าระวังแต่ไม่มี IP จัดการ                                       |

ทุกการตรวจข้ามแถวที่ลบแล้ว และ (ยกเว้น `sample_data`) ข้ามข้อมูลตัวอย่าง

## ผลบนข้อมูลตั้งต้น (2026-10-02)

- error 48: `not_in_zabbix` 47 (ปิดใน **M08** จับคู่ host + M12 ผู้ใช้ API), `sample_data` 1 (`ap-ba-2-1`)
- warning 90: `no_room` 39, `no_uplink` 13 (NVR ทั้งหมด), `no_mgmt_ip` 38 — งาน FIELD/ทะเบียนเติมภายหลัง ไม่บล็อก G1
- โครงสร้างถูกต้อง: `no_position`, `duplicate_ip`, `uplink_missing`, `uplink_cycle` = 0

**สถานะเงื่อนไขเสร็จ:** โค้ดและรายงานพร้อม; ศูนย์ error ต้องรอ M08 และการตัดสินใจเรื่อง AP ตัวอย่าง

## วิธีใช้

```bash
# บน sbc-ubuntu (dev)
cd /opt/sbc-noc/src
docker compose --env-file /opt/sbc-noc/dev.env -f infra/compose/compose.dev.yml run --rm noc-dev-migrate \
  node node_modules/@sbc-noc/db/dist/check-cli.js
# หรือเปิด http://noc-dev.sbc.lan (เฉพาะวง 192.168.1.x)
```
