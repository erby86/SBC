# M13 — API พื้นฐาน

ตาม modules-by-gate-v2: Fastify, zod, OpenAPI (`/docs`), `/health`, `/metrics`, log pino, ตั้งค่าจาก `.env` (ADR-005)

**เสร็จเมื่อ:** CI build image ได้; `/health` ตอบ; เอกสาร OpenAPI เปิดได้

## สิ่งที่ทำ

| ไฟล์                           | หน้าที่                                                                                                                     |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `apps/api/src/app.ts`          | `buildApp()` (async): zod type provider ตรวจ request และกรอง response ตาม schema; OpenAPI สร้างจาก schema เดียวกัน          |
| `apps/api/src/metrics.ts`      | `/metrics` แบบ Prometheus: ค่าพื้นฐานของ process (`noc_api_*`) + `noc_api_http_request_duration_seconds` แยกตาม route/สถานะ |
| `apps/api/src/server.ts`       | อ่าน env (`DATABASE_URL`, `REDIS_URL`, `PORT`, `HOST`, `LOG_LEVEL`), log pino แบบ JSON ปิดบัง header authorization/cookie   |
| `apps/web/nginx.conf.template` | `/api/docs` → `/api/docs/` (ไฟล์ของหน้าเอกสารอ้างอิงแบบ relative)                                                           |

- route ใหม่ทุกตัวต้องมี `schema` (zod) → ขึ้นใน `/docs` เอง และ response ที่ไม่ตรง schema จะได้ 500 แทนการส่งข้อมูลเกินออกไป
- OpenAPI `servers: [{ url: '/api' }]` เพราะเบราว์เซอร์เข้าผ่าน nginx ของเว็บ (`http://noc-dev.sbc.lan/api/...`)
- `/metrics` ไม่อยู่ในเอกสาร (hide) — ใช้กับ M35 เฝ้าตัวเอง; เข้าได้เฉพาะวง mgmt ตาม access list ของ NPM
- แพ็กเกจ: `fastify-type-provider-zod` 7, `@fastify/swagger` 9, `@fastify/swagger-ui` 6, `prom-client` 15

ทดสอบ: `/health`, `/health/ready` (ผ่าน/ล้ม/ค้าง), `/registry/checks`, `/docs/json` มีครบ 3 path + `servers=/api`, หน้า `/docs/` เป็น HTML, `/metrics` นับ request ราย route, response ผิด schema → 500
