# ADR-0005: ที่เก็บ secret

- **สถานะ:** Accepted
- **วันที่:** 2026-10-02

## บริบท

ระบบต้องใช้ token ของ Zabbix, OIDC และรหัสฐานข้อมูล ซึ่งห้ามหลุดเข้า repo

## การตัดสินใจ

- CI ใช้ Gitea secrets
- เซิร์ฟเวอร์ใช้ไฟล์ `.env` ใน `/opt/sbc-noc` นอก repo สิทธิ์ 600
- ฐานข้อมูลเก็บเฉพาะ `secret_ref` (ชื่ออ้างอิง) ไม่เก็บค่าจริง
- repo มีเพียง `.env.example` ที่ค่าว่าง

## ผลที่ตามมา

- CI สแกนด้วย gitleaks (ADR-0016)
- หมุน secret ได้โดยไม่ต้องแก้ฐานข้อมูล
- ประเมินที่เก็บ secret โดยเฉพาะ (เช่น Infisical หรือ Vault) ใน G5
