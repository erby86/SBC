# ADR-0002: รหัสอุปกรณ์

- **สถานะ:** Accepted
- **วันที่:** 2026-10-02

## บริบท

hostname ตามมาตรฐานโรงเรียนอาจเปลี่ยนเมื่อย้ายห้องหรือเปลี่ยนมาตรฐาน แต่ระบบต้องอ้างอุปกรณ์ด้วยค่าที่ไม่เปลี่ยน

## การตัดสินใจ

- `code` รหัสภายในสั้น คงที่ตลอดอายุอุปกรณ์ ใช้อ้างอิงในฐานและ URL
- `hostname` ตามมาตรฐานโรงเรียน เปลี่ยนได้ เก็บเป็นฟิลด์แยก

## ผลที่ตามมา

- ความสัมพันธ์ทั้งหมดอ้าง `code`/id ไม่อ้าง hostname
- การเปลี่ยน hostname ต้องบันทึกประวัติ
