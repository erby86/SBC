# ADR-0006: รูปแบบรหัสป้าย

- **สถานะ:** Accepted
- **วันที่:** 2026-10-02

## บริบท

ป้ายสาย ตู้ และจุด LAN เดิมไม่มีมาตรฐานเดียว ทำให้ค้นหาและตรวจสอบยาก

## การตัดสินใจ

ตาม sbc-noc-schema-design-v1.2 ข้อ 5:

- สายไฟเบอร์: `FO-<ต้นทาง>-<ปลายทาง>-<NN>` เช่น `FO-B2-BA-01`; สาย LAN ระหว่างตึก `CU-...`
- ตู้: `RK-<อาคาร>-<ห้อง>-<NN>` เช่น `RK-B2-SRV-01`
- จุด LAN: `<อาคาร>-<ชั้น>-<เลขห้อง>-<NN>` เช่น `B2-3-2310-05` (รหัสอาคารตัวพิมพ์ใหญ่)
- ป้ายเดิมที่หน้างานเก็บใน `attributes.legacy_label` และใช้รูปแบบนี้กับป้ายใหม่

> แก้ไข 2026-10-02 (M03): ฉบับแรกของ ADR นี้ใน repo ใช้ตัวอย่างตัวพิมพ์เล็กและฟิลด์ `legacy_label` ซึ่งไม่ตรงกับเอกสารออกแบบ แก้ให้ตรงกับ design v1.2

## ผลที่ตามมา

- ตรวจรูปแบบด้วย zod schema ใน `packages/shared` (`outletCodeSchema`, `rackCodeSchema`, `cableCodeSchema`)
- ค้นหาได้ทั้งป้ายใหม่และป้ายเดิม ระหว่างช่วงเปลี่ยนป้าย
