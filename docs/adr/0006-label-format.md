# ADR-0006: รูปแบบรหัสป้าย

- **สถานะ:** Accepted
- **วันที่:** 2026-10-02

## บริบท

ป้ายสาย ตู้ และจุด LAN เดิมไม่มีมาตรฐานเดียว ทำให้ค้นหาและตรวจสอบยาก

## การตัดสินใจ

- สาย: `FO-` (ไฟเบอร์) และ `CU-` (ทองแดง)
- ตู้: `RK-`
- จุด LAN: `<อาคาร>-<ชั้น>-<ห้อง>-<NN>` เช่น `b1-2-205-01`
- ป้ายเดิมเก็บในฟิลด์ `legacy_label`

## ผลที่ตามมา

- ตรวจรูปแบบด้วย zod schema ใน `packages/shared`
- ค้นหาได้ทั้งป้ายใหม่และป้ายเดิม ระหว่างช่วงเปลี่ยนป้าย
