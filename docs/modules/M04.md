# M04 — นำเข้าข้อมูลตั้งต้น

ตาม modules-by-gate-v2: สคริปต์นำเข้า อาคาร/ชั้น/ผังจากต้นแบบ, LOC 173 + LOC-187, อุปกรณ์ + ISP 4, ไฟเบอร์ 8 เส้น + สี, VLAN, ทีม STF

**เสร็จเมื่อ:** จำนวนแถวตรงกับต้นทาง; รันซ้ำได้ไม่ซ้ำข้อมูล (idempotent)

## ข้อมูลต้นทาง (`infra/seed/`)

| ไฟล์                    | เข้าตาราง                                                                                                                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `buildings.csv` (8)     | `core.sites` (sbc), `core.buildings`, `core.floors` (42 ชั้น)                                                                                                                                    |
| `areas.csv` (173)       | `core.locations`, `core.location_metrics` (`registry_pc_count`, source `sbc_asset`)                                                                                                              |
| `devices.csv` (50)      | `net.devices`, `catalog.models`, `net.vlans` (14), `net.device_vlans`, `net.links` (uplink 36)                                                                                                   |
| `prototype-layout.json` | `viz.building_shapes` (8), `viz.area_shapes` (4), `net.cables` ไฟเบอร์ 8 เส้น + `viz.link_routes` (สี), `core.staff` STF-01..07, `core.organizations` + `net.wan_circuits` (ISP 4 ตามลำดับสำรอง) |

`prototype-layout.json` ดึงจาก `docs/prototype/sb-noc-3d-baseline-v3.html` (BLD, FIBER, STAFF, WAN)

## การตัดสินใจ (ยืนยันกับผู้ใช้ 2026-10-02)

- `SPORT-01..04` ได้เลข LOC ใหม่จาก `core.next_loc_code()` (LOC-188..191) รหัสเดิมเก็บใน `attributes.legacy_code` (ADR-0001)
- อุปกรณ์ตามไฟล์ 50 แถว (46 + ISP 4) แทน "49 + 4" ใน modules-by-gate-v2
- แถว `ตัวอย่าง` (AP 1 ตัว) → `data_status = 'sample'`, `lifecycle = 'planned'` (ADR-0014) ให้ M07 แสดง
- ชื่อรุ่นที่เป็นคำอธิบาย (`สวิตช์ประจำชั้น`, `สวิตช์ main`, `จุดรับไฟเบอร์`) ไม่สร้างเป็นรุ่น เก็บใน `attributes.model_note`
- รหัสสายไฟเบอร์ `FO-<อาคารต้นทาง>-<อาคารปลายทาง>-NN` จากอาคารของอุปกรณ์ต้นทาง/ปลายทาง (ADR-0006) เช่น `FO-B2-BA-01`
- ทุกการเขียนบันทึก audit ด้วย actor `seed:M04`

## โค้ด

- `packages/db/src/seed/` — `csv.ts` (อ่าน CSV), `map.ts` (แปลงค่า), `files.ts`, `import.ts` (upsert ใน transaction เดียว เขียนเฉพาะแถวที่ค่าเปลี่ยน)
- `packages/db/src/seed-cli.ts` — พิมพ์ตารางจำนวนที่คาด/ที่มีจริง ล้ม (exit 1) ถ้าไม่ตรง

## วิธีรันบน sbc-ubuntu (dev)

```bash
/opt/sbc-noc/src/infra/scripts/pg-backup.sh      # backup ก่อนเขียนข้อมูล
cd /opt/sbc-noc/src
docker compose --env-file /opt/sbc-noc/dev.env -f infra/compose/compose.dev.yml run --rm \
  -v /opt/sbc-noc/src/infra/seed:/seed:ro noc-dev-migrate node node_modules/@sbc-noc/db/dist/seed-cli.js /seed
```
