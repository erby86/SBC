# ADR-0009: โครงสร้าง repo

- **สถานะ:** Accepted
- **วันที่:** 2026-10-02

## บริบท

monorepo มีหลายแอปและแพ็กเกจ ต้องมีโครงที่คงที่และทิศทางการเรียกใช้ชัดเจน

## การตัดสินใจ

- กำหนดโครงชั้นบนครบ (`apps/`, `packages/`, `infra/`, `docs/`, `tests/`) และสร้างใน M01
- โฟลเดอร์ย่อยของโมดูลสร้างตอนเริ่มโมดูลนั้น
- ทิศทางการเรียกใช้บังคับด้วย dependency-cruiser ใน CI
- เปลี่ยนโครงชั้นบนต้องมี ADR ใหม่

## ผลที่ตามมา

- CI ล้มเมื่อ import ผิดทิศทาง เช่น `apps/web` → `packages/db`
- โครงสร้างอธิบายไว้ใน `docs/architecture.md`
