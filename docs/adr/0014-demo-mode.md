# ADR-0014: โหมดสาธิต

- **สถานะ:** Accepted
- **วันที่:** 2026-10-02

## บริบท

ต้องการอบรมและสาธิตเหตุการณ์ (เช่น สายขาด สวิตช์ล่ม) โดยไม่ต้องรอเหตุจริง

## การตัดสินใจ

- สถานการณ์ตัวอย่างเก็บเป็น fixture ใน repo
- มีโหมดอบรมที่เปิดได้เฉพาะ dev/staging หรือผู้ดูแลระบบ

## ผลที่ตามมา

- prod ต้องแสดงชัดเจนเมื่ออยู่ในโหมดอบรม
- fixture ใช้ซ้ำใน test และ e2e ได้
