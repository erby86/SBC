# M16 — ข้อมูลสดผ่าน WebSocket

ตาม modules-by-gate-v2: ช่อง WebSocket ส่ง snapshot + ส่วนที่เปลี่ยน, fallback ดึงทุก 30 วินาที

**เสร็จเมื่อ:** หน้าทดสอบเห็นสถานะเปลี่ยนภายใน 30 วินาทีหลัง Zabbix เปลี่ยน

## การทำงาน

```
worker (M15, ทุก 30 s) ──publish──▶ Redis <prefix>status:updates ──▶ api LiveHub ──ws──▶ หน้าเว็บ
                                                                                └─ ถ้า ws ใช้ไม่ได้: GET /api/status ทุก 30 s
```

| ไฟล์                           | หน้าที่                                                                                                                                                                                    |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `packages/shared/src/live.ts`  | ข้อความ `snapshot` / `delta` (zod), `diffSnapshots`, `applyDelta` — api และเว็บใช้ชุดเดียวกัน                                                                                              |
| `apps/api/src/routes/live.ts`  | `LiveHub`: subscribe Redis 1 connection ต่อ api, ส่ง snapshot ตอนเชื่อมต่อ แล้ว delta ทุกรอบ; ค้างเองเมื่อเงียบเกิน 2 นาที; Redis ล่มตอนเริ่ม → api ยังทำงาน และลอง subscribe ใหม่ทุก 30 s |
| `apps/web/nginx.conf.template` | `/api/status/ws` ส่งต่อแบบ WebSocket (Upgrade, timeout 1 ชม.)                                                                                                                              |
| `apps/web/src/LiveStatus.tsx`  | หน้าทดสอบบนหน้าแรก: โหมดการเชื่อมต่อ, เวลาอัปเดต/ค้าง, จำนวนตามสถานะ, เหตุ, รายการการเปลี่ยนแปลงล่าสุด                                                                                     |

- ข้อความมี `version` เพิ่มทีละ 1; delta = อุปกรณ์ที่สถานะเปลี่ยน (`ok` = กลับปกติ) + รายการเหตุ/จำนวน/ความสดทั้งชุด (เล็กมาก)
- WebSocket ไม่รับคำสั่งจาก client; `maxPayload` 1 KB
- **NPM ต้องเปิด "Websockets Support"** ที่ proxy host `noc-dev.sbc.lan` (ไม่เปิด → หน้าเว็บตกไปโหมดดึงทุก 30 s เอง)

ทดสอบ: delta ไป-กลับระหว่างสถานการณ์ M38 ได้ snapshot เดิม; hub ส่ง snapshot แล้ว delta, ค้างเองครั้งเดียว, ทำงานต่อเมื่อ Redis ล่ม; WebSocket จริงผ่าน `injectWS`; หน้าเว็บ: ใช้ delta, แสดงค้าง, ws ปิด → ดึง `/api/status` ทุก 30 s

**บน dev (2026-10-03):** ผู้ใช้ยืนยันว่าเสร็จ — หน้าทดสอบเชื่อมต่อแบบ WebSocket และเห็นสถานะเปลี่ยนตาม Zabbix
