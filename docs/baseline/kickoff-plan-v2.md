ข้อสังเกต

- เส้นทางวิกฤตเดิมยังใช้ได้; งานที่เลื่อนได้โดยไม่กระทบ: M06, M38, M34, M36

## 5. จังหวะการทำงาน

- จบโมดูล: รายงานผลตามเงื่อนไข "เสร็จเมื่อ" ปิด issue อัปเดต `CLAUDE.md` แล้วรอยืนยันก่อนเริ่มโมดูลถัดไป
- ทุกวันศุกร์ 30 นาที: ทบทวน issue ที่ค้าง ความเสี่ยง และเรื่องที่ต้องตัดสินใจ (ทำคนเดียวจึงควรส่งสรุปมาให้ Claude ตรวจเทียบ baseline เป็นมุมมองที่สอง)
- ปิด gate: อัปเดต baseline ฉบับใหม่ใน Drive และคัดลอกเข้า `docs/baseline/` ของ repo
- การตัดสินใจใหม่ทุกครั้ง: เพิ่ม ADR ทั้งใน repo และ baseline

## 6. บทบาทและความเสี่ยงจากการทำคนเดียว

- STF-01 รับ OWNER, DEV, NET, FIELD ทำเต็มเวลา
- ความเสี่ยง: ถ้าติดงานอื่นหรือลา โครงการหยุดทั้งหมด; ลดด้วยเอกสารที่คนอื่นรับช่วงได้ (`CLAUDE.md`, ADR, `docs/modules/`, issue ใน Gitea)
- ความเสี่ยง: ตรวจงานตัวเอง; ลดด้วยเงื่อนไข "เสร็จเมื่อ" ที่ตรวจได้ชัด, CI ที่เข้ม และส่งผลแต่ละโมดูลให้ Claude ตรวจเทียบ baseline
- ข้อเสนอ: ให้ทีม STF ช่วยงาน FIELD ตามแบบฟอร์ม
