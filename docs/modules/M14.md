# M14 — API ทะเบียนและผัง

ตาม modules-by-gate-v2: endpoint อาคาร/ชั้น/ห้อง/อุปกรณ์/สาย/ผัง 3D/ค้นหา (อ่าน) พร้อม ETag

**เสร็จเมื่อ:** ข้อมูลที่หน้า 3D ต้องใช้ดึงได้ครบจาก API ไม่มีข้อมูลฝังในหน้าเว็บ

## Endpoint (อ่านอย่างเดียว, เอกสารที่ `/api/docs/` กลุ่ม registry)

| path                              | ให้อะไร                                                                                          |
| --------------------------------- | ------------------------------------------------------------------------------------------------ |
| `GET /registry/layout`            | ทุกอย่างที่ฉาก 3D ใช้ในครั้งเดียว: site, อาคาร+รูปทรง, พื้นที่, ห้อง, อุปกรณ์, การเชื่อมต่อ, สาย |
| `GET /registry/buildings[/:code]` | อาคาร; ตัวเดียวมีรายชั้นพร้อมจำนวนห้อง/อุปกรณ์                                                   |
| `GET /registry/locations[/:loc]`  | ห้อง (กรอง `building`, `floor`) + จำนวนเครื่องตาม SBC ASSET                                      |
| `GET /registry/devices[/:code]`   | อุปกรณ์ (กรอง `building`, `floor`, `role`, `layer`); ตัวเดียวมี downlink และรหัสในระบบอื่น       |
| `GET /registry/links`, `/cables`  | ต้นไม้ uplink (สื่อ, สาย, แกน, สีเส้น) และสายจริง                                                |
| `GET /registry/search?q=`         | ค้นหาอาคาร (ชื่อ/ชื่อเรียก), ห้อง (LOC/ชื่อ/เลขห้อง), อุปกรณ์ (รหัส/ชื่อ/hostname/IP/MAC)        |

- รูปแบบข้อมูลอยู่ที่ `packages/shared/src/registry.ts` (zod) — api ใช้กรอง response, หน้าเว็บใช้ parse ได้ชุดเดียวกัน
- query อยู่ที่ `packages/db/src/registry/read.ts`; ไม่คืนแถวที่ลบแล้ว และไม่คืนข้อมูลตัวอย่าง (`data_status = sample`)
- ETag แบบ weak จาก hash ของ body (`@fastify/etag`) + `Cache-Control: no-cache` → หน้า 3D ส่ง `If-None-Match` ได้ 304 เมื่อทะเบียนไม่เปลี่ยน
- ค้นหา: ไม่สนตัวพิมพ์, ตรงทั้งคำ (รหัส/IP/LOC) ขึ้นก่อน แล้ว อาคาร → ห้อง → อุปกรณ์, สูงสุด 50

ทดสอบ: ฐานจริง (seed) — layout ผ่าน schema กลาง: อาคาร 8 (มีรูปทรงครบ), ห้อง 173, อุปกรณ์ 49 (ไม่รวมตัวอย่าง), สาย 8, เส้นไฟเบอร์ c1036→m-b1 สี `#00e5ff`; อาคาร b2 มี 3 ชั้น; LOC-031 มี 40 เครื่อง; c2116 มี downlink; ค้นหา IP/LOC/ชื่อเรียก; api — ETag/304, เปลี่ยนข้อมูลแล้ว ETag เปลี่ยน, กรองจาก query, 400/404, ครบใน OpenAPI
