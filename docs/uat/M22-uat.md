# UAT G4 — หน้า 3D ต่อข้อมูลจริง (M22)

ใช้ปิด G4: "UAT กับทีมผ่าน, จอทีวี ≥ 30 เฟรม/วินาที, ภาพหน้าจอ 3 ขนาดไม่มีข้อความเลยขอบ" (baseline-v8 §9)

- ที่ทดสอบ: `http://noc-dev.sbc.lan/` (dev, ข้อมูลจริงจาก Zabbix) และ `http://noc-dev.sbc.lan/?demo=s8down` (โหมดสาธิต)
- ผู้ทดสอบ: STF 2–3 คนที่ **ไม่ได้** สร้างระบบ อย่างน้อย 1 คนใช้มือถือ
- ผู้คุม (STF-01): อ่านโจทย์ให้ฟังทีละข้อ **ห้ามอธิบายวิธีทำ** จับเวลา จดว่าติดตรงไหน
- โหมดสาธิตใช้ในงาน 1–3 เพื่อให้ทุกคนเจอเหตุการณ์เดียวกัน (มีแถบเหลือง "ข้อมูลสาธิต")
- ผ่าน = ทำสำเร็จภายในเวลาที่กำหนดโดยไม่ต้องช่วย; ผ่านงานหลัก (1–3) ทุกคน และงานอื่นอย่างน้อย 2 ใน 3 คน

## ก่อนเริ่ม (ผู้คุม)

1. Ctrl+F5 หน้า `http://noc-dev.sbc.lan/` เห็นอาคาร 8 หลังและเวลาอัปเดตเดินอยู่
2. ล้างการแนะนำครั้งแรกเพื่อดูว่าผู้ทดสอบเข้าใจเองไหม: เปิด DevTools → Console → `localStorage.clear()` แล้วโหลดใหม่
3. เปิด `http://noc-dev.sbc.lan/?demo=s8down` ไว้อีกแท็บ

## จอทีวี (≥ 30 fps)

บนเครื่องที่จะใช้เป็นจอจริง (หรือสเปกเดียวกัน, จอ 1920×1080):

1. เปิด `http://noc-dev.sbc.lan/?tv&fps` เต็มจอ (F11)
2. รอ 15 วินาที ดูชิป `.. fps` ที่แถบบน (เฉลี่ย 5 วินาที) จดค่า 3 ครั้งห่างกัน 1 นาที
3. ผ่าน = ทุกค่า ≥ 30; ถ้าต่ำกว่าและหน้าเปลี่ยนเป็นโหมดประหยัดเอง ให้จดไว้ (ยังไม่ผ่าน)

หรือรัน Playwright จากเครื่องนั้น (มี GPU): `E2E_BASE_URL=http://noc-dev.sbc.lan E2E_MIN_FPS=30 pnpm --filter @sbc-noc/e2e e2e --project=desktop-1920 specs/tv.spec.ts`

## ภาพหน้าจอ 3 ขนาด

CI job `e2e` (PR เข้า main) ถ่ายภาพ 1920×1080 มืด / 1366×768 สว่าง / มือถือ 390×844 ทุกหน้าหลัก และล้มเมื่อมีข้อความเลยขอบ — ภาพอยู่ใน artifact `e2e-shots` ของ run นั้น
ตรวจกับ dev จริงได้ด้วย `E2E_BASE_URL=http://noc-dev.sbc.lan pnpm --filter @sbc-noc/e2e e2e` (ต้องมี Chromium ของ Playwright ในเครื่องที่รัน)
