# ADR-0004: เครื่องออนไลน์ห้องคอมพิวเตอร์

- **สถานะ:** Accepted
- **วันที่:** 2026-10-02

## บริบท

ต้องการแสดงจำนวนเครื่องออนไลน์ในห้องคอมฯ โดยยังไม่มีทะเบียนคอมพิวเตอร์ (ADR-0003)

## การตัดสินใจ

ใช้ Zabbix network discovery แบบ ICMP สแกนช่วง IP ของห้องคอมฯ แต่ละห้อง แล้ว sbc-noc อ่านผลจาก Zabbix

## ผลที่ตามมา

- ไม่ต้องติดตั้ง agent บนเครื่องนักเรียน
- ความแม่นยำขึ้นกับการแบ่งช่วง IP ต่อห้อง ต้องดูแลตาราง IP range
- ไฟร์วอลล์เครื่องที่ปิด ICMP จะแสดงเป็นออฟไลน์
