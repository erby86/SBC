## ต้องตัดสินใจตอน M04

- รหัส `SPORT-01`..`SPORT-04` (อาคารกีฬา Walkthrough) ไม่ใช่รูปแบบ `LOC-NNN` — จะออกเลข LOC ใหม่จาก `next_loc_code()` หรือคงรหัสเดิม
- modules-by-gate-v2 (M04) เขียน "อุปกรณ์ 49 + ISP 4" แต่ไฟล์มี 46 + 4 = 50 แถว (ตรงกับ baseline-v8 "อุปกรณ์ 50 แถว") — ยึดไฟล์นี้
- สถานะข้อมูล: `ต้องตรวจ` 47, `วางแผน` 2, `ตัวอย่าง` 1 → map เป็น `data_status`
- ไฟเบอร์ 8 เส้น + สี, VLAN, ทีม STF และผัง 3D ไม่มีในไฟล์นี้ — M04 ดึงจากต้นแบบ `docs/prototype/`
