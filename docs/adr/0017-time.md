# ADR-0017: เวลา

- **สถานะ:** Accepted
- **วันที่:** 2026-10-02

## บริบท

ข้อมูลเหตุการณ์มาจากหลายอุปกรณ์ ถ้าเวลาไม่ตรงกันจะเรียงเหตุการณ์ผิด

## การตัดสินใจ

- ทุกเครื่องซิงก์ NTP จาก CCR2116
- เก็บเวลาเป็น UTC (`timestamptz`)
- แสดงผลเป็นเขต Asia/Bangkok และปี พ.ศ.

## ผลที่ตามมา

- แปลงเวลาเฉพาะที่ชั้นแสดงผล
- ฟังก์ชันจัดรูปแบบวันที่อยู่ใน `packages/shared`
