# ADR-0008: ที่อยู่ระบบ

- **สถานะ:** Accepted
- **วันที่:** 2026-10-02

## บริบท

ระบบเป็นเครื่องมือภายในของฝ่ายไอที ไม่มีความจำเป็นต้องเปิดสู่อินเทอร์เน็ต

## การตัดสินใจ

- ใช้งานใน LAN เท่านั้น: `noc.sbc.lan`
- container registry: `git.sbc.lan`
- ไฟล์บนเซิร์ฟเวอร์ sbc-ubuntu: `/opt/sbc-noc`

## ผลที่ตามมา

- ไม่ต้องใช้ certificate สาธารณะ ใช้ CA ภายใน
- การเข้าจากนอกโรงเรียนต้องผ่าน VPN (ADR-0012)
