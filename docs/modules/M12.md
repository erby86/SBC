# M12 — ผู้ใช้ API Zabbix + discovery ห้องคอมฯ

ตาม modules-by-gate-v2: ผู้ใช้ API อ่านอย่างเดียว, ผู้ใช้สำหรับรับเรื่อง (ใช้ใน G5), token, discovery rule ICMP ช่วง IP ห้องคอมฯ (ADR-004), แนวทางใช้ maintenance

**เสร็จเมื่อ:** token ใช้งานได้; ตัวเลขเครื่องออนไลน์ห้องคอมฯ มีค่า

## ทำแล้ว (2026-10-02, Zabbix 7.0.31, `http://zabbix.sbc.lan`)

| สิ่งที่ตั้ง                  | ค่า                                                                                                                                                                                                                                                                          |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| User role `noc-api-read`     | User type `User`; UI เปิดแค่ Dashboards (Zabbix บังคับ ≥ 1); services None; actions ปิดทั้งหมด; API allow list: `host.get hostgroup.get hostinterface.get item.get trigger.get problem.get event.get maintenance.get history.get trend.get drule.get dhost.get dservice.get` |
| User group `noc-api`         | Frontend access Disabled; Host permissions **Read** เฉพาะ `01-Core-Routers`, `02-Core-Switches`, `03-Dist-Switches-*`                                                                                                                                                        |
| User `noc-api-read`          | group `noc-api`, role `noc-api-read`                                                                                                                                                                                                                                         |
| API token `sbc-noc-dev-read` | เก็บใน `/opt/sbc-noc/dev.env` เป็น `ZABBIX_TOKEN_READ` (600) + `ZABBIX_URL=http://zabbix.sbc.lan/api_jsonrpc.php`                                                                                                                                                            |

ผลทดสอบ: `hostgroup.get` เห็นเฉพาะกลุ่มเครือข่าย (ไม่เห็น Zabbix servers); `host.get` ได้ 8 host พร้อม IP; `host.update` → `No permissions to call "host.update"` ✅

## ยังค้าง

- **discovery ห้องคอมฯ** — ผู้ใช้เลื่อนไปทำทีหลัง; วงที่ยืนยันแล้ว `192.168.40/50/60/70/80/90.0/24` (ตาม VLAN อาคาร); ต้องรู้ว่าห้องคอมฯ มีช่วง IP แยกในวงหรือไม่ ก่อนนับรายห้อง → เงื่อนไขเสร็จข้อ 2 ยังไม่ผ่าน
- **ผู้ใช้รับเรื่อง** — เลื่อนไปทำพร้อม M24 (ไม่ทิ้ง token ที่เขียนได้ไว้โดยไม่ใช้)
- แนวทางใช้ maintenance — ทำพร้อม M25

## ข้อสังเกต

- ชื่อกลุ่ม `01-Core-Routers` มีอักขระล่องหน `U+200B` นำหน้า — ควรพิมพ์ชื่อใหม่ใน Zabbix
- Zabbix มี host เครือข่าย 8 ตัว (ทะเบียน 46) — ส่วนที่เหลือเพิ่มใน M10; IP ตรงทะเบียน 5 ตัว (.1 .2 .11 .12 .21), อีก 3 ตัว (.15 .152 .157) ทะเบียนยังไม่มี IP
