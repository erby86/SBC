# ADR-0003: ขอบเขตครุภัณฑ์

- **สถานะ:** Accepted
- **วันที่:** 2026-10-02

## บริบท

SBC ASSET ยังพัฒนาไม่เสร็จ การซิงก์ครุภัณฑ์ทุกประเภทตั้งแต่แรกจะทำให้ข้อมูลซ้ำซ้อน

## การตัดสินใจ

- ระยะแรก sbc-noc ดูแลเฉพาะอุปกรณ์เครือข่าย UPS และ NVR
- คอมพิวเตอร์จะซิงก์จาก SBC ASSET หลัง SBC ASSET ปิด Phase 2

## ผลที่ตามมา

- schema ต้องเผื่อประเภทคอมพิวเตอร์ไว้แต่ยังไม่เปิดใช้
- ห้องคอมฯ ระยะแรกแสดงสถานะออนไลน์ผ่าน ADR-0004 แทน
