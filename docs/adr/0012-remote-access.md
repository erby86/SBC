# ADR-0012: การเข้าใช้จากนอกโรงเรียน

- **สถานะ:** Accepted
- **วันที่:** 2026-10-02

## บริบท

เจ้าหน้าที่ไอที (STF) ต้องดู NOC ได้นอกเวลาและนอกโรงเรียน โดยไม่เปิดระบบสู่อินเทอร์เน็ต (ADR-0008)

## การตัดสินใจ

- ใช้ WireGuard บน CCR2116 สำหรับ STF เท่านั้น
- แจ้งเตือนเหตุการณ์ผ่าน Telegram

## ผลที่ตามมา

- ต้องจัดการ peer/key ของ WireGuard ต่อบุคคล
- ระบบไม่ต้องมีหน้า login สาธารณะ
